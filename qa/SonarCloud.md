SonarCloud: Analiza bugs, vulnerabilidades, code smells, cobertura y duplicación de código.

TRABAJO CON SONARCLOUD
Paso 1: Acceder a Sonar Cloud
- Para acceder a SonarCloud es necesario contar con una cuenta en esta, para ello nos dirigimos a su página web: https://sonarcloud.io
- Hacemos clic en "Log in" → "Log in with GitHub", esto nos facilita el trabajo con los repositorios existentes en GitHub.
- Autorizamos el acceso a nuestra cuenta GitHub.
- Elegimos el plan con el que deseamos trabajar en SonarCloud y este importará automáticamente tus organizaciones y repositorios.
- 
Paso 2: Importar repositorio
- En el dashboard de SonarCloud, damos clic en "+" → "Analyze new project"
- Seleccionamos la organización GitHub (usuario).
- Buscamos el repositorio que deseamos trabajar.
- Hacemos clic en "Set Up"

Paso 3: Configurar el análisis automático
- Para esto nos dirigimos a: Administration -> Analysis method
- Ubicamos la sección Automatic Analysis y la activamos.
